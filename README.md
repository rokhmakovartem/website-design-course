# Мій HTML-сайт (університетський проєкт)

## Про проект
Це навчальний веб-проект, створений для закріплення базових та просунутих навичок роботи з HTML5, CSS3 та JavaScript. Проект являє собою багатосторінковий сайт-візитку з каталогом курсів веб-розробки.

## Що реалізовано

### Базова структура та розмітка
* **Багатосторінкова архітектура:** Головна, Про мене, Курси, Контакти
* **Семантична та доступна розмітка:** Використання тегів `header`, `main`, `footer`, `nav`, `figure`, а також ARIA-атрибутів
* **Контент:** Робота з таблицями (`table`, `thead`, `tbody`, `caption`) та мультимедіа (`video`, `audio`)

### Інтерактивні UI-компоненти
* **Перемикач світлої/темної теми** зі збереженням у `localStorage`
* **Акордеон (FAQ)** з плавною анімацією через `scrollHeight`
* **Модальне вікно (лайтбокс)** для зображень без "стрибків" макета
* **Кнопка "Нагору"** з плавною прокруткою

### Робота з формами
* **Кастомна JavaScript-валідація** в реальному часі
* **Динамічний лічильник символів** для `textarea`
* **Автозбереження чернеток** у `localStorage`
* **Перехоплення форми** та виведення даних через `FormData`

### Каталог курсів (Практична робота №9-10)
* **Асинхронне завантаження даних** з JSON через `fetch()` та `async/await`
* **Динамічний рендеринг карток** на основі масиву об'єктів
* **Стани інтерфейсу:** loading (завантаження), error (помилка), empty result (порожній результат)
* **Пошук у реальному часі** з debounce-оптимізацією
* **Фільтрація за категоріями:** HTML, CSS, JavaScript, Інструменти
* **Сортування:** за назвою, рейтингом, ціною
* **Список обраного** зі збереженням у `localStorage`
* **Кнопка "Показати ще"** для поступового відображення контенту
* **Модальне вікно деталей курсу** з повною інформацією

### Оптимізація та архітектура
* **Єдиний реєстр SVG-іконок** у JavaScript
* **CSS-змінні** для консистентної колірної схеми
* **Повна адаптивність** під мобільні пристрої (RWD)
* **Модульна структура коду** з окремими функціями для кожної задачі

## Структура JSON-даних (courses.json)

Кожен курс містить поля:
* `id` — унікальний ідентифікатор
* `title` — назва курсу
* `category` — категорія (html, css, javascript, tools)
* `description` — короткий опис
* `fullDescription` — повний опис для модального вікна
* `level` — рівень складності (beginner, intermediate, advanced)
* `duration` — тривалість курсу
* `lessons` — кількість уроків
* `rating` — рейтинг (1-5)
* `price` — ціна (0 = безкоштовно)
* `featured` — чи є курс популярним
* `image` — URL іконки
* `topics` — масив тем курсу

## Ключові функції JavaScript

| Функція | Опис |
|---------|------|
| `loadCourses()` | Асинхронне завантаження JSON через fetch() |
| `initCatalogPage()` | Ініціалізація каталогу з обробкою станів |
| `renderCatalog()` | Динамічний рендеринг карток |
| `createCourseCard()` | Генерація HTML картки курсу |
| `applyFiltersAndSort()` | Застосування пошуку, фільтрів та сортування |
| `sortCourses()` | Сортування масиву курсів |
| `toggleFavorite()` | Додавання/видалення з обраного |
| `openCourseModal()` | Відкриття модального вікна деталей |
| `debounce()` | Оптимізація частих викликів функцій |

## Як запустити

1. Завантажте папку з проектом на свій комп'ютер
2. Відкрийте `index.html` у браузері (Google Chrome, Firefox, Safari)
3. Для коректної роботи каталогу курсів **використовуйте локальний сервер**:
   - VS Code: розширення "Live Server"
   - Python: `python -m http.server 8000`
   - Node.js: `npx serve`

> **Примітка:** Через політику безпеки браузерів (CORS), fetch() не працює з `file://` протоколом. Використовуйте локальний HTTP-сервер.
