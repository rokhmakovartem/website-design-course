# Мій HTML-сайт (університетський проєкт)

## Про проект
Це навчальний веб-проект, створений для закріплення базових та просунутих навичок роботи з HTML5, CSS3 та JavaScript. Проект являє собою багатосторінковий сайт-візитку з каталогом курсів веб-розробки та повноцінним REST API CRUD-інтерфейсом.

---

## Практична робота №11–12: REST API та CRUD-операції

### Швидкий старт

1. **Встановіть json-server** (якщо ще не встановлено):
   ```bash
   npm install -g json-server
   ```

2. **Запустіть локальний API-сервер** з кореневої папки проєкту:
   ```bash
   json-server --watch db.json --port 3000
   ```
   Сервер буде доступний за адресою: `http://localhost:3000`

3. **Відкрийте фронтенд** — запустіть локальний HTTP-сервер (Live Server у VS Code, або):
   ```bash
   npx serve .
   ```

4. Перейдіть на сторінку **Курси** (`pages/courses.html`)

> **Важливо:** json-server і фронтенд мають працювати одночасно у двох окремих терміналах.

---

### Реалізовані CRUD-операції

| Метод | Маршрут | Дія |
|-------|---------|-----|
| GET | `/courses` | Завантажити список курсів (з пошуком, фільтром, сортуванням, пагінацією) |
| GET | `/courses/:id` | Завантажити один курс за ID |
| POST | `/courses` | Створити новий курс |
| PATCH | `/courses/:id` | Оновити існуючий курс |
| DELETE | `/courses/:id` | Видалити курс |

### Де що знаходиться

- **Каталог курсів** (`pages/courses.html`) — список з кнопками "Редагувати" та "Видалити"
- **Форма створення/редагування** (`pages/admin.html`) — відкривається кнопкою "Додати курс" або "Редагувати"
- **Деталі курсу** (`pages/course-details.html`) — відкривається кнопкою "Детальніше"

## Що реалізовано

### Базова структура та розмітка (попередні практичні)
* **Багатосторінкова архітектура:** Головна, Про мене, Курси, Контакти
* **Семантична та доступна розмітка:** `header`, `main`, `footer`, `nav`, ARIA-атрибути
* **Контент:** Таблиці, мультимедіа (`video`, `audio`)

### Інтерактивні UI-компоненти
* **Перемикач світлої/темної теми** зі збереженням у `localStorage`
* **Акордеон (FAQ)** з плавною анімацією через `scrollHeight`
* **Модальне вікно (лайтбокс)** для зображень
* **Кнопка "Нагору"** з плавною прокруткою

### Робота з формами
* **Кастомна JavaScript-валідація** в реальному часі
* **Динамічний лічильник символів** для `textarea`
* **Автозбереження чернеток** у `localStorage`
* **Перехоплення форми** та виведення даних через `FormData`

### Каталог курсів з REST API (Практична №11-12)
* **REST API** через json-server (`db.json`) — ресурс `/courses`
* **API-шар** у `js/api.js` — окремі функції для GET, POST, PATCH, DELETE
* **Отримання списку** через GET із підтримкою query-параметрів
* **Стани інтерфейсу:** `loading`, `error`, `empty`, `success`
* **Пошук, фільтрація, сортування** — через URLSearchParams до json-server
* **Пагінація** — через `_page` / `_limit`, відображення номерів сторінок
* **Створення курсу** — форма `admin.html` → POST → redirect
* **Редагування курсу** — GET by id → заповнення форми → PATCH
* **Видалення курсу** — кастомне модальне вікно підтвердження → DELETE → оновлення списку
* **Клієнтська валідація** форми перед відправкою
* **Toast-повідомлення** про успіх/помилку після кожної операції
* **Синхронізація UI** — після CRUD інтерфейс завжди актуальний

### Бонусні завдання (з зірочкою)
* **Б1:** Збереження стану фільтрів у URL (`URLSearchParams`) — відновлення після reload
* **Б2:** Окрема сторінка деталей курсу (`pages/course-details.html`) з GET by id
* **Б4:** Розділення create/edit у формі — різні заголовки, кнопки, повідомлення
* **Б5:** Кастомне модальне вікно підтвердження видалення (замість `confirm()`)

## Структура JSON-ресурсу `db.json`

Кожен курс (`/courses`) містить поля:

| Поле | Тип | Опис |
|------|-----|------|
| `id` | number | Унікальний ID (auto-assign) |
| `title` | string | Назва курсу |
| `category` | string | `html` / `css` / `javascript` / `tools` |
| `description` | string | Короткий опис |
| `fullDescription` | string | Повний опис |
| `level` | string | `beginner` / `intermediate` / `advanced` |
| `duration` | string | Тривалість (напр. "4 тижні") |
| `lessons` | number | Кількість уроків |
| `rating` | number | Рейтинг 0–5 |
| `price` | number | Ціна в грн (0 = безкоштовно) |
| `featured` | boolean | Популярний курс |
| `status` | string | `published` / `draft` |
| `image` | string | URL іконки |
| `topics` | string[] | Масив тем |
